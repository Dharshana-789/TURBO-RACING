# TURBO-RACING
HIGH SPEED TURBO RACING GAME
🏎️ TURBO RACING PRO

A fun and exciting 2D arcade racing game built using Python and Pygame.

Dodge enemy cars, collect gold coins, activate Nitro and enjoy exciting racing animations!

🎮 Game Features

🏎️ Detailed sports car graphics

🚗 5 AI enemy cars

🛣️ Scrolling racing road

🪙 Animated gold coins

💰 Collect 10 points per coin

🔥 Nitro flame animation

💨 Drifting smoke effects

💥 Crash sparks and screen shake

✨ Animated coin collection effects (+10)

🏁 3-2-1-GO countdown

🌧️ Rain and water splash effects

⚡ Speed line animations

🎨 Animated start menu

🔄 Restart option

🕹️ Controls
Key	Action
Mouse Click	Start Race
↑ Arrow	Move Up
↓ Arrow	Move Down
← Arrow	Move Left
→ Arrow	Move Right
SHIFT	Nitro
SPACE	Drift
R	Restart
ESC	Main Menu
🛠️ Requirements
Python 3
Pygame

Install Pygame:

bash
pip install pygame

▶️ How to Run
Install Python.
Install Pygame.
Save the game code as turbo_racing.py.
Run the following command:
bash
python turbo_racing.py

🪙 Coin System
Collect gold coins on the road.
Each collected coin gives 10 points.
Avoid enemy cars to survive longer.
🎯 Objective

Drive your sports car, avoid enemy vehicles, collect as many coins as possible and achieve the highest score!
